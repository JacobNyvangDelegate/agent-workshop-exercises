What is this module about?

About Autonomous Agents in Copilot Studio

Autonomous agents can respond to events without waiting for a user to start a conversation. Triggers and conditions determine when the agent may act and which tools it can use in the process.

In this guide, you will learn about autonomous triggers, add Outlook functionality, create an email trigger, and test and validate the agent's behavior before publishing the changes.
