Exercise 00 · Workshop setup · ~15 minutes

Workshop Setup

Prepare your account, environment, and workshop materials before you begin building agents.

What you’ll do

  • Select your workshop user from the participant assignment sheet
  • Sign in with the workshop account supplied by your facilitator
  • Select the correct Power Platform environment
  • Complete first-time setup and set the interface language to English
  • Download the Agent in a Day student files
  • Import the workshop solution from the student files

Setup video

Review the setup at your own pace

🎧 Watch the video below and follow the full setup process step by step before you begin the exercises.

Step 1: Choose your workshop user

  1. Open the Workshop User Assignment Sheet.
  2. Select an available workshop user.
  3. Keep the same user for the entire workshop.

Step 2: Sign in and select your environment

  1. Open Copilot Studio in a private browser window.
  2. Sign in using the workshop account you selected in Step 1.
  3. Complete MFA and any first-time prompts. Set the interface language to English when prompted.
  4. Use the environment picker to select the environment assigned to you.

Step 3: Download the student files

Workshop material

Download the files before continuing with the setup.

Download student files ↓
  1. Extract AgIAD_Student_Files.zip to a folder you can easily find again.
  2. Keep the extracted AgIAD Student Files folder available for the rest of the workshop. It contains the workshop solution and knowledge files used in later exercises.

Step 4: Import the workshop solution

  1. Open Power Apps in the same environment.
  2. Select Solutions, then choose Import solution.
  3. From the extracted student-files folder, select AgentsinaDay_1_0_0_13_DoNotUnzip.zip.
  4. Wait for the import to finish before continuing. The solution provides the sample data and resources used in later exercises.

Step 5: Verify your setup

  1. Confirm that you can open Copilot Studio in the correct environment.
  2. Confirm that the imported workshop solution appears under Solutions.
  3. Keep the workshop-material folder available for the rest of the day.

Checkpoint

  • ✅ Workshop user selected in the participant assignment sheet
  • ✅ Signed in with the assigned account
  • ✅ Correct environment selected
  • ✅ MFA and first-time setup completed
  • ✅ Agent in a Day student files downloaded and extracted
  • ✅ Workshop solution imported
