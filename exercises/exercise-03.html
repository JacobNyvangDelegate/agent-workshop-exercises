What is this module about?

About Tools in Copilot Studio

Tools enable a Copilot Studio agent to do more than answer questions. They can connect the agent to actions, workflows, data, and other systems so it can complete specific tasks for the user.

In this guide, you will learn about the different tool types, build a custom prompt tool for a support scenario, and create an agent flow that handles an order cancellation.
