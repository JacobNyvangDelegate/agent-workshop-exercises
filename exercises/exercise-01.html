What is this module about?

About Agents in Copilot Chat

Microsoft 365 Copilot Chat lets you create agents that support specific tasks and scenarios. You can start with a ready-made agent template or build a custom agent from scratch.

In this guide, you will work with agent instructions, knowledge sources, capabilities, and suggested prompts. You will also test and improve the agent's responses directly in Copilot Chat.
