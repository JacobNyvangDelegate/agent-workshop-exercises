Copilot Studio & Microsoft 365 Copilot Workshop

Context& Agent In a Day

A facilitated onsite workshop with four practical learning sessions, using the official Microsoft Learn Agent in a Day modules as the participant guide.

Workshop journey

The workshop follows one focused demo flow: build declarative agents in Microsoft 365 Copilot Chat, create and ground a conversational agent in Copilot Studio, extend it with tools and an agent flow, then add an autonomous email trigger.

Each exercise corresponds to one Microsoft Learn module and includes one direct module reference plus a short self-check.
